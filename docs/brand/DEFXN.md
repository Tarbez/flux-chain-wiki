# DEFXN / Agreement fabric

The block mesh is the brand foundation. Backgrounds, lifecycle illustrations and “How it works” share one cell renderer: `ArkUI.createMeshFabric`. The brand system develops that existing structure rather than introducing a separate ornamental language.

## Color roles

`css/flux-themes.css` is the single source of color. `css/themes.css` is generated by the SDK and still loads first for fonts and sizes, but every color token it declares is redeclared in `flux-themes.css`; `tests/theme-color-contrast.cjs` fails if one is missing.

| Role | Token | Use |
| --- | --- | --- |
| Signal | `--signal` | The one DEFXN color: brand marks, critical information, record numbers |
| Action | `--action` (= signal) | Every primary call to action: filled for the principal one, outlined elsewhere. `--primary`, `--complement`, `--accent` and the SDK `--action-*` names all resolve to it |
| Reference | `--reference` | Navigation, evidence links, stage pickers, disclosure. Quieter than action |
| Success / Warning / Danger | `--success`, `--warning`, `--danger` | State only, never decoration or brand. `--trust` and `--live` map to success, `--drift` to warning |

Text descends `--text-strong` → `--text` → `--text-muted` → `--text-faint`, each a distinct step that still reads at 4.5:1 or better. Surfaces climb `--canvas` → `--surface` → `--raised` → `--nested` with visible separation, and default borders read as edges. Component styles take colors from these tokens, not literals.

## Palettes

One dark palette (Night, key `ghost`) and one light palette (Day, key `glacier`). The signal keeps the same ember hue in both; themes change the canvas, surfaces and ink weights, not the brand. Earlier keys stay valid: `clay`, `ochre` and `marine` resolve to Night, and `grove`, `moss` and `bone` to Day; the settings panel migrates saved choices.

## Backgrounds

Blocks uses the network arrangement, Traces the stepped logic path, and Layers the checking rows, all drawn in the same 16 × 12 cells used by the existing shared page diagrams. Background mode uses neutral ink and omits narrative captions. Patterns are static by default. Each pattern saves its own size and spacing presets, structure, visibility, animation preference and loop delay. Size and spacing use keyboard-accessible radio groups; Structure changes the arrangement, and Visibility adjusts decorative ink. Remove pattern clears all decorative lattice layers. Optional 1.8-second mesh scans with gentle opacity pulses wait 300 ms–10 seconds between loops; they stop when hidden, globally paused, or reduced motion is requested. Slider cards pair explanatory labels, percentage/second badges, filled tracks, 44px interaction areas and endpoint descriptions. Native input updates preserve pointer capture and keyboard focus without rerendering. Sliders affect the decorative pattern only; narrative diagrams keep their canonical geometry. Nodes marks linked intersections, Routes draws stepped paths, Tiles groups alternating cell clusters, and Frames outlines repeated block regions. Wave is removed; saved Wave preferences migrate to Traces. None removes the pattern.

Choices persist under `defxn-motif-v1`. Older ornament choices migrate to mesh patterns; the prior weave choice migrates to Wave. Patterns are decorative, excluded from accessibility and fade out through the reading area. Mobile reduces their opacity.

The color regression (`tests/theme-color-contrast.cjs`) checks every theme key for: palette authority, an invariant signal used by every action token, distinct semantic roles, 4.5:1 inks on canvas and surfaces, a four-step text ladder, surface separation, visible default borders, and no literal colors in the guarded stylesheets. These are scoped assertions, not a blanket claim about every site element.
