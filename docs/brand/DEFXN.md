# DEFXN / Agreement fabric

The block mesh is the brand foundation. Backgrounds, lifecycle illustrations and “How it works” share one cell renderer: `ArkUI.createMeshFabric`. The brand system develops that existing structure rather than introducing a separate ornamental language.

## Color roles

| Role | Use |
| --- | --- |
| Primary | Critical page information, outcomes, record numbers and important status |
| Complementary | Calls to action: continue, run, connect, unlock and open CMS |
| Reference | Lower-level navigation, evidence links, stage pickers and disclosure controls |

Keep surfaces dim and neutral. Preserve quiet body text and metadata. Spend colors on their roles, not on background decoration. Accent, trust and warning compatibility tokens resolve within the three-color system; genuine errors retain the explicit danger token. Text and position continue to convey meaning alongside color.

## Backgrounds

Blocks uses the network arrangement, Traces the stepped logic path, and Layers the checking rows, all drawn in the same 16 × 12 cells used by the existing shared page diagrams. Background mode uses neutral ink and omits narrative captions. Patterns are static by default. Eight palettes pair dark and light variants of four core colors: red, green, blue and yellow. The picker groups them by appearance with core-color swatches; no pink or purple role inks. Each pattern saves its own size and spacing presets, structure, visibility, animation preference and loop delay. Size and spacing use keyboard-accessible radio groups; Structure changes the arrangement, and Visibility adjusts decorative ink. Remove pattern clears all decorative lattice layers. Optional 1.8-second mesh scans with gentle opacity pulses wait 300 ms–10 seconds between loops; they stop when hidden, globally paused, or reduced motion is requested. Slider cards pair explanatory labels, percentage/second badges, filled tracks, 44px interaction areas and endpoint descriptions. Native input updates preserve pointer capture and keyboard focus without rerendering. Sliders affect the decorative pattern only; narrative diagrams keep their canonical geometry. Nodes marks linked intersections, Routes draws stepped paths, Tiles groups alternating cell clusters, and Frames outlines repeated block regions. Wave is removed; saved Wave preferences migrate to Traces. None removes the pattern.

Choices persist under `defxn-motif-v1`. Older ornament choices migrate to mesh patterns; the prior weave choice migrates to Wave. Patterns are decorative, excluded from accessibility and fade out through the reading area. Mobile reduces their opacity.

The color regression measures all three role inks and complementary action labels at a minimum 4.5:1 across eight palettes. It also rejects role colors that collapse into indistinguishable grey tints. These are scoped assertions, not a blanket claim about every site element.
