# DEFXN / Agreement fabric

The block mesh is the brand foundation. Backgrounds, lifecycle illustrations and “How it works” share one cell renderer: `ArkUI.createMeshFabric`. The brand system develops that existing structure rather than introducing a separate ornamental language.

## Color roles

`css/flux-themes.css` is the single source of color. It is generated by `scripts/build-flux-themes.cjs`: edit the families there and rerun `node scripts/build-flux-themes.cjs`. `css/themes.css` (SDK-generated) still loads first for fonts and sizes, but every color token it declares is redeclared in `flux-themes.css`, and `tests/theme-color-contrast.cjs` enforces that.

| Role | Token | Where it may appear |
| --- | --- | --- |
| Primary | `--primary` | Identity: the hero accent and a few small marks per view. Never a button, never a heading color |
| Secondary | `--secondary` (= `--action`, `--complement`) | The main call to action: filled once per view, outlined in its shades when it repeats (the header's Run DEFXN) |
| Reference | `--reference` | Secondary actions and links only. Never decoration |
| Success / Warning / Danger | `--success`, `--warning`, `--danger` | State only. `--trust` and `--live` map to success, `--drift` to warning |

Everything else (headings, record numbers, labels, captions, rules) is neutral, so the few colored things keep their weight.

### Shades

Every role has a ladder, written as HSL triplets so `hsl(var(--x) / a)` still works:

| Step | Use |
| --- | --- |
| `-100` | Subtle fill (resting background of an outlined action) |
| `-200` | Hover fill |
| `-300` | Border |
| `-400` | Muted mark: rules, connectors, inactive indicators |
| `-500` | Base, the same as the bare token |
| `-600` | Hover on a filled action |
| `-700` | Pressed / strongest |
| `-ink` | Text on a `-500` fill |

Shades are mixed against each palette's own canvas, so they read as the same hue at lower intensity rather than as translucent overlays.

Text descends `--text-strong` → `--text` → `--text-muted` → `--text-faint`, each a distinct step at 4.5:1 or better. Surfaces climb `--canvas` → `--surface` → `--raised` → `--nested` with visible separation.

## Palettes

Five relaxed families, each in a dark and a light palette. Saturation stays at or below 50%, and lightness is solved per hue so every ink clears its contrast target.

| Family | Dark / light key | Primary | Secondary (main CTA) | Reference |
| --- | --- | --- | --- | --- |
| Ember | `ghost` / `glacier` | Terracotta | Jade | Slate blue |
| Tide | `clay` / `grove` | Sea blue | Apricot | Periwinkle |
| Moss | `ochre` / `moss` | Olive | Clay coral | Dusty blue |
| Dune | `marine` / `bone` | Sand | Jade teal | Slate blue |
| Dusk | `dusk` / `dawn` | Lavender | Peach | Teal |

No two families share a primary hue or the same trio, and each family keeps its hues across its dark and light palettes. Ember dark is the default.

## Backgrounds

Blocks uses the network arrangement, Traces the stepped logic path, and Layers the checking rows, all drawn in the same 16 × 12 cells used by the existing shared page diagrams. Background mode uses neutral ink and omits narrative captions. Patterns are static by default. Each pattern saves its own size and spacing presets, structure, visibility, animation preference and loop delay. Size and spacing use keyboard-accessible radio groups; Structure changes the arrangement, and Visibility adjusts decorative ink. Remove pattern clears all decorative lattice layers. Optional 1.8-second mesh scans with gentle opacity pulses wait 300 ms–10 seconds between loops; they stop when hidden, globally paused, or reduced motion is requested. Slider cards pair explanatory labels, percentage/second badges, filled tracks, 44px interaction areas and endpoint descriptions. Native input updates preserve pointer capture and keyboard focus without rerendering. Sliders affect the decorative pattern only; narrative diagrams keep their canonical geometry. Nodes marks linked intersections, Routes draws stepped paths, Tiles groups alternating cell clusters, and Frames outlines repeated block regions. Wave is removed; saved Wave preferences migrate to Traces. None removes the pattern.

Choices persist under `defxn-motif-v1`. Older ornament choices migrate to mesh patterns; the prior weave choice migrates to Wave. Patterns are decorative, excluded from accessibility and fade out through the reading area. Mobile reduces their opacity.

The color regression (`tests/theme-color-contrast.cjs`) checks all ten palettes for: palette authority, secondary owning every action token, distinct roles, full shade ladders that climb in order, readable text on every filled role, 4.5:1 inks on canvas and surfaces, relaxed saturation, a four-step text ladder, surface separation, visible default borders, five distinct families per appearance, and no literal colors in the guarded stylesheets. These are scoped assertions, not a blanket claim about every site element.
