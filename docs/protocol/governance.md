# Governance

Governance defines how protocol policies, authority rosters, thresholds, and changes are proposed and accepted. It must identify the governed object, eligible decision-makers, required threshold, activation rule, and evidence of the decision.

## Minimum record

A governance claim should include:

- proposal or action identifier;
- policy revision and governed object;
- authority roster;
- required threshold and collected approvals;
- activation condition and activation evidence;
- observation time and artifact digest.

## Current boundary

The source defines governance and authority concepts, but this audit did not establish a public governance interface or independent production activation. Public-facing descriptions must therefore link to evidence or use `Unverified`.

Named-network creation is not a governance action and does not create a trusted membership set. See [networks](../operators/networks.md).
