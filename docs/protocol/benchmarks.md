# Benchmarks

Benchmarks are evidence only when the workload, environment, source revision, method, sample size, and result artifact are available together. A number without those fields is not publishable evidence.

## Required benchmark record

- record ID and observation date;
- capability under test;
- source revision and build configuration;
- hardware, operating system, and network conditions;
- dataset or generated workload;
- warm-up, repetitions, and aggregation method;
- raw artifact location and digest;
- result with units and uncertainty;
- known limitations.

## Current status

No canonical public benchmark artifact was established during this audit. Benchmark claims on the public site must remain `Unverified` or be removed until a complete record is added to the [evidence registry](../evidence/registry.md).
