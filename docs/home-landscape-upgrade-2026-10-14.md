# Homepage / chain landscape

This pass responds to the mismatch between a diagram-card hero, a utility-heavy header and generic lower sections.

- New headline: “Not one chain. A world of them.” Copy remains editable in the home manifest; metadata and fallback use the same promise.
- The home-only rich scene is a continuous isometric landscape: five independent histories, seven records per history, one highlighted chain and separate cross-chain reference traces. It is explicitly illustrative, not network telemetry. The detailed original walkthrough remains on `/chain`.
- Stage controls, example selection, pause, reduced motion, offscreen suspension and teardown remain connected to the existing scene controller.
- Home navigation loses redundant icons and the tiny brand descriptor. Account remains available in the full menu and compact header. Routing and account state logic are unchanged.
- Shared palette generation now produces vivid accents against near-neutral surfaces. All ten stored theme keys remain compatible. Contrast and semantic roles are still tested; only the previous muted-chroma aesthetic constraint changed.
- The architecture, audience, evidence, questions and closing sections use the same type rhythm, fine borders, square controls and record motif. Benchmarks retain their dates, fleet scope and exclusions.

Local-only implementation. Shared palettes affect other routes; layout changes are scoped to the homepage. No deployment or claims of production adoption.
